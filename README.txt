# Studio Marcelle Souza — novo site

Arquivos:
- index.html
- style.css
- script.js
- img/ (pasta para as fotos reais)

## Antes de publicar
1. No `index.html`, substitua `5541999999999` pelo número real do WhatsApp.
2. Substitua as imagens ilustrativas da galeria pelas fotos reais do Studio.
3. Substitua a área "FOTO da Marcelle" pela foto real da profissional.
4. Faça upload dos arquivos para o repositório do GitHub Pages.

O layout da galeria foi preparado para 3 fotos por linha no desktop e também 3 por linha em telas pequenas, seguindo o exemplo enviado.
